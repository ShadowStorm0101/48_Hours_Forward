# Version Control Workflow

## Workflow Used

The team used a feature branch workflow throughout development.

Features and fixes were developed on separate branches before they were merged into the main branch.

# Branch Naming Convention

Examples of branch names used throughout development:

- feature/dashboard-access-control
- feature/map-add-location
- email-notifications
- front-end-help-page
- integration/dashboard-postgres
- milestone-effects
- resources-page

# Commit Practices

The team aimed to:

- Make regular commits
- Keep commits focused on specific features/fixes
- Use meaningful commit messages

Example commit styles:

- Add email reminder notifications
- Fix dashboard PostgreSQL integration
- Implement moderator access control
- Improve frontend help page styling

# Collaboration

GitHub was used throughout the project for collaboration and version control.

Branches were merged into the main branch once features were completed and tested.
